# MangaX v3.0.9

วันที่ออก: 2026-10-10

รุ่นแก้ไขด่วนของ v3.0.8 แนะนำให้ทุกคนที่ติดตั้ง v3.0.5 หรือ v3.0.8 ติดตั้งทับด้วย MangaX-Setup.exe ตัวใหม่

## แก้ไข

- **อ่านข้อความ (OCR) ไม่ได้ในชุดติดตั้ง** ไฟล์พจนานุกรม `alphabet-all-v7.txt` ในชุดติดตั้งใช้ตัวขึ้นบรรทัดแบบ Windows ทำให้ค่า SHA-256 ไม่ตรงและโปรแกรมไม่ยอมโหลด ตัวตรวจยอมรับไฟล์ข้อความที่ต่างกันเฉพาะตัวขึ้นบรรทัดแล้ว ไฟล์โมเดลยังตรวจทุกไบต์เหมือนเดิม
- **อัปเดตในโปรแกรมไม่ได้ ("Unable to fetch origin/main")** ชุดติดตั้งรุ่นก่อนมีข้อมูลรับรองชั่วคราวของระบบ build ที่หมดอายุแล้วติดมาในโฟลเดอร์ `.git` ชุดติดตั้งรุ่นนี้ไม่มีข้อมูลนั้นแล้ว
- ข้อผิดพลาดที่ไม่เกี่ยวกับ API ถูกแสดงเป็น "HTTP 429" เมื่อข้อความมีเลข 429 ปนอยู่ในค่าอื่น
- แถบสถานะระหว่างแปลหลายภาพแสดงเป็นภาษาจีนเสมอ ตอนนี้แสดงตามภาษาที่เลือกครบทั้ง 7 ภาษา
- Codex: ค้นหาโปรแกรม Codex จากค่าของบัญชี Windows โดยตรง ไม่ใช้ค่า `PATH` ที่ไฟล์ `.env` เปลี่ยนได้

## สำหรับเครื่องที่ติดตั้ง v3.0.5 หรือ v3.0.8 อยู่

ปุ่มอัปเดตในโปรแกรมของสองรุ่นนั้นใช้ไม่ได้ ให้เลือกทางใดทางหนึ่ง

- เปิด MangaX-Setup.exe ตัวใหม่แล้วติดตั้งทับโฟลเดอร์เดิม
- หรือรันคำสั่งนี้ครั้งเดียวใน PowerShell แล้วกดอัปเดตในโปรแกรม (เปลี่ยน `C:\MangaX` ให้ตรงกับโฟลเดอร์ที่ติดตั้ง)

  ```
  C:\MangaX\PortableGit\cmd\git.exe -C C:\MangaX config --local --unset-all "http.https://github.com/.extraheader"
  ```

## ข้อจำกัดที่ทราบ

- MangaX-Setup.exe ยังไม่ได้เซ็นลายเซ็นดิจิทัล Windows SmartScreen จะเตือนตอนเปิดครั้งแรก
- การแปลด้วย Codex ต้องติดตั้ง Codex CLI แยกเอง โปรแกรมยังไม่ติดตั้งให้
- การแปลด้วย Codex ยังไม่ใช้ `system_prompt` จากไฟล์พรอมป์ต์ ใช้เฉพาะรายการคำศัพท์
