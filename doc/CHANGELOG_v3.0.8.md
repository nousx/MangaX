# MangaX v3.0.8

วันที่ออก: 2026-10-09

## เพิ่มใหม่

- **MangaX-Setup.exe** ตัวติดตั้งไฟล์เดียว ตรวจการ์ดจอของเครื่อง เลือกชุดที่ตรงกัน (NVIDIA CUDA 13.0 / CUDA 12.6, AMD ROCm หรือ CPU) ดาวน์โหลด ตรวจ SHA-256 แตกไฟล์ และสร้างทางลัดให้ โหลดต่อจากจุดเดิมได้เมื่อเน็ตหลุด
- หน้าตั้งค่าการแปลแสดงสถานะบัญชี Codex (ล็อกอินแล้ว / ยังไม่ล็อกอิน / ไม่พบ Codex CLI) พร้อมปุ่มล็อกอินและปุ่มดาวน์โหลด Codex CLI แต่ละคนล็อกอินด้วยบัญชี ChatGPT ของตัวเอง

## แก้ไข

- ชุด portable เปิดไม่ขึ้นเมื่อเครื่องมี PyTorch ติดตั้งอยู่ในโฟลเดอร์ผู้ใช้ของ Python 3.12 ตัวเปิดโปรแกรมไม่อ่านแพ็กเกจจากโฟลเดอร์นั้นแล้ว

## ข้อจำกัดที่ทราบ

- MangaX-Setup.exe ยังไม่ได้เซ็นลายเซ็นดิจิทัล Windows SmartScreen จะเตือนตอนเปิดครั้งแรก
- การแปลด้วย Codex ต้องติดตั้ง Codex CLI แยกเอง โปรแกรมยังไม่ติดตั้งให้
