# MangaX v4.0.0

วันที่ออก: 2026-10-11

## เปลี่ยนพฤติกรรม

- **ล้อเมาส์ในหน้าแก้ไข** หมุนล้อเมาส์เลื่อนหน้าขึ้นลง กด Ctrl ค้างแล้วหมุนเพื่อซูม ส่วนการปรับขนาดฟอนต์ของกล่องข้อความที่เลือก (หรือย่อขยายภาพแปะ) ย้ายจาก Ctrl ไปเป็น Ctrl + Shift แล้วหมุน Shift แล้วหมุนยังปรับขนาดแปรงเหมือนเดิม รุ่นก่อนหมุนล้อเมาส์แล้วซูมทุกครั้ง
- **ข้อความแจ้งเตือนเป็นภาษาอังกฤษ** ข้อความสถานะ กล่องแจ้งเตือน และข้อความผิดพลาดที่เคยแสดงเป็นภาษาจีนเสมอ ตอนนี้แสดงเป็นภาษาอังกฤษเสมอ ข้อความกลุ่มนี้ยังไม่เปลี่ยนตามภาษาที่เลือกในโปรแกรม
- **เว็บเซิร์ฟเวอร์** ข้อความผิดพลาดของ API และคำอธิบายในหน้า OpenAPI เป็นภาษาอังกฤษ ชื่อกลุ่มผู้ใช้เริ่มต้นของการติดตั้งใหม่เป็นภาษาอังกฤษ
- **ชื่อฟอนต์** ฟอนต์ที่มากับโปรแกรมไม่มีคำนำหน้า MangaX แล้ว

## เพิ่ม

- เปิดโปรแกรมโดยไม่มีหน้าต่าง console ค้าง ใช้ `Win-Start-Console.bat` เมื่ออยากเห็น log สด
- แปลด้วย Claude Code CLI ที่ลงชื่อเข้าใช้ไว้ในเครื่อง
- เลือกโมเดลและระดับการคิด (reasoning effort) ของ Codex และ Claude CLI ได้ในหน้าตั้งค่า
- Codex ใช้คำแนะนำด้านสำนวนจากไฟล์พรอมป์ต์ และบอกสาเหตุเมื่อรันไม่สำเร็จ
- ปุ่ม "ทำต่อจากที่ค้าง" สำหรับคิวที่หยุดกลางทาง และคิวยาวรันต่อเองได้โดยไม่ต้องเฝ้า
- คำนวณการตัดบรรทัดที่บันทึกไว้ใหม่ได้โดยไม่ต้องแปลซ้ำ
- ภาษาไทย: ชื่อจากรายการคำศัพท์อยู่ในบรรทัดเดียว และมีตัวเลือกลบเครื่องหมายท้ายประโยค
- ฟอนต์ไทยชุด TLWG
- ปุ่มเลือกทั้งหมดในรายการไฟล์

## แก้ไข

- บรรทัดภาษาไทยถูกตัดกลางคำ
- หน้าที่บันทึกไว้โดยไม่มี mask เปิดแล้วไม่แสดงผล
- ส่งออก PSD แบบ "เฉพาะสคริปต์" ต้องเปิดสวิตช์ PSD เต็มก่อนจึงทำงาน
- โปรแกรมปิดตัวเมื่อเมนูฟอนต์ปิดหลังหน้าต่างย่อยหายไปแล้ว
- หน้าต่างเลือกฟอนต์พื้นหลังโปร่ง หัวตารางที่แปลแล้วถูกตัด และตัวเลือกในหน้าแก้ไขเป็นชุดไม่มีชื่อ
- ข้อความในโปรแกรมที่ขาดไปใน 4 ภาษา
- การรันผ่านบรรทัดคำสั่งใช้ค่าตั้งไม่ครบเท่าหน้าต่างโปรแกรม
- ความล้มเหลวของการดาวน์โหลดและ API ไม่ถูกบันทึกลงไฟล์ log

## ความปลอดภัย

- ปิดบังคีย์ API และข้อมูลรับรองในทุกเส้นทางที่เขียนลง log และข้อความผิดพลาด รวมถึง traceback
- เมื่อคำขอ API ล้มเหลว บันทึกเฉพาะรหัสสถานะและชื่อโฮสต์
- Codex และ Claude CLI เริ่มทำงานด้วยค่าแวดล้อมของบัญชี Windows เท่านั้น

## ข้อจำกัดที่ทราบ

- MangaX-Setup.exe ยังไม่ได้เซ็นลายเซ็นดิจิทัล Windows SmartScreen จะเตือนตอนเปิดครั้งแรก
- การแปลด้วย Codex และ Claude CLI ต้องติดตั้ง CLI แยกเอง โปรแกรมยังไม่ติดตั้งให้
