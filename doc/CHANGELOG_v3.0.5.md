# MangaX v3.0.5

วันที่ออก: 2026-10-09

เวอร์ชันแรกของ MangaX ซึ่งแยกมาจาก [Manga Translator UI](https://github.com/hgmzhn/manga-translator-ui) v3.0.4 โดย hgmzhn

## เพิ่มใหม่

- เมนูภาษาไทยทั้งโปรแกรม
- ฟอนต์ไทย 34 ตระกูล 300 แบบ ติดมากับโปรแกรม
- ตัวเลือกฟอนต์แสดงข้อความของกรอบที่เลือกด้วยฟอนต์แต่ละแบบ พร้อมหมวด รายการโปรด และป้ายเตือนเมื่อฟอนต์ไม่มีอักษรที่ต้องใช้
- แปลผ่าน Codex CLI ด้วยบัญชี ChatGPT ที่ล็อกอินไว้ ไม่ต้องกรอก API key
- แท็บผู้ช่วยในตัวแก้ไข: OCR ทั้งหน้า, คิวงานทั้งบทที่ทำต่อได้, บริบทเรื่องและเสียงตัวละคร, ตรวจคุณภาพก่อนส่งออก
- OCR ในเครื่องใช้ได้โดยไม่ต้องตั้งค่า API ของบริการแปล
- หน้าเกี่ยวกับ: เครดิตโครงการต้นทาง

## ความปลอดภัย

- โหมดเว็บฟังที่ `127.0.0.1` เป็นค่าเริ่มต้น ใช้ `--host` เพื่อเปิดให้เครื่องอื่นเข้าถึง
- การสร้างแอดมินคนแรกทำได้จากเครื่องเดียวกัน หรือใช้ `MANGA_TRANSLATOR_SETUP_TOKEN`
- แก้การแทรก HTML ในหน้าผู้ดูแล และจำกัดอักขระของชื่อผู้ใช้ใหม่
- จำกัดขนาดและจำนวนไฟล์เมื่อแตก archive
- ตรวจ SHA-256 ของโมเดลก่อนโหลด
- อัปเดต urllib3 เป็น 2.8.0 และ multidict เป็น 6.9.1

## ข้อจำกัดที่ทราบ

- หลังนำผลจากแท็บผู้ช่วยเข้าตัวแก้ไข ภาพบนจอยังเป็นภาพต้นฉบับ ไฟล์ที่ส่งออกถูกต้อง
- ขั้นจัดตัวอักษรของแท็บผู้ช่วยไม่ย่อขนาดฟอนต์ให้พอดีกรอบเอง
- โมเดล OCR `48px` อ่านภาษาไทยไม่ได้
